# 大乐透持续分析与预测系统

## 架构

```
.agents/skills/dlt-analyzer/
├── SKILL.md
└── data/
    ├── draws.json
    ├── predictions.json
    └── model.json
```

三种模式：首次初始化(1000期) / 增量更新(追加+对比) / 纯预测。

## 数据管理

API: `webapi.sporttery.cn/gateway/lottery/getHistoryPageListV1.qry?gameNo=85`
首次拉取1000期，分10批，必须在 lottery.gov.cn 域名下调用。
增量：读最新期号→拉30期→筛新期号→追加→触发对比。

## 预测模型

多维统计：频次、遗漏值、近30期趋势、奇偶比、和值、区间、尾号。
评分: `score = gap×0.5 + (5-freq30)×2.5 + (N/7-freq)×0.3`
约束：奇偶2:3或3:2，区间1-2:1-2:1-2，和值67-111，全距≥15，热≥2+冷≥1。
输出：主推、偏热、偏冷三组。

## 对比与优化

新开奖→回填predictions.json→算命中→调权重(学习率0.05)。

## 指令

| 指令 | 行为 |
|------|------|
| 分析大乐透 | 增量+预测 |
| 对比结果 | 回填命中 |
| 初始化 | 拉1000期 |
| 偏冷门 | gap+50% |
