## round-29 (2026-09-24) - 新增 EVO-20 模型（20元/期 预测算法）

- 变更内容：新增独立算法 EVO-20（`evo20_model.py` + `evo20_backtest.py` + `evo20_result.json` + `EVO20模型报告.md` + `26110期EVO20预测单.md` + `evo20_tickets.json`），评估口径从「6+3 命中≥4」改为「20元/期资金表现」。算法四层：①票务结构（1张票10注单式20元 ≥ 派奖「单票≥18元」门槛，不买追加）；②选号评分（多窗口频次+遗漏+重号/邻号融合，静态权重，复用 skill 特征体系）；③评分配额+覆盖发牌（每号保底1次+高分加位，轮转发牌成10注，压回撤/提中奖期占比）；④精确结算引擎（枚举 21,425,712 种开奖 + 993期 walk-forward 回测 + 长视野蒙特卡洛 + 盈亏平衡分析）。奖金口径按用户要求简化：一等奖 500 万、二等奖 20 万平价，固定奖现行规则，派奖期三~六等+50%、七等翻倍。
- 变更原因：用户要求「每期投入20元、长期盈利」的新算法。数学事实（本模型精确验证）：单注固定奖 EV=0.5459 元 + 浮动奖 0.4201 元 = 0.9659 元/2元票，回报率 48.3%（派奖期 53.0%）；开奖独立均匀+奖金平价 ⇒ EV 与选号无关（与 round-25 实验结论互证），长期盈利数学上不可达。EVO-20 定位为该约束下最优解：真实 EV 杠杆（派奖资格）全拿 + 选号自由度全部用于命中分布工程。
- 影响文件：evo20_model.py、evo20_backtest.py、evo20_result.json、EVO20模型报告.md、26110期EVO20预测单.md、evo20_tickets.json（均新增）。不修改 algorithms.py / SKILL.md 既有算法，旧口径不受影响
- 变更前指标：不适用（新口径）。参考：hitGe4 口径下各算法与随机基线 2.04% 无显著差异（round-25 结论）
- 变更后指标：993 期 walk-forward：EVO-20 净 -13,790 元（ROI -69.4%），中奖期占比 53.4%（随机 50.3%、same10 7.0%、v1cold10 18.1%），零奖最长连 8 期（v1cold 44 期）；蒙特卡洛 10 年 P(终局盈利) 1.4%、P(期间曾盈利) 10.7%；盈亏平衡需一等奖 2,716 万（5.4×假设）或固定奖 ×3.66
- 恢复方法：删除上述新增文件即完全回滚，不影响既有算法链路

- 变更内容：新增 `neighbor_backtest.py`，对「base / base+重号 / base+重号+跨期邻号 / base+跨期邻号」四组做独立前向回测（数据 draws.json 19123-26096，共 1010 期）
