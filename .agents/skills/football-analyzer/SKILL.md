# 足球比分概率预测系统

## 重要声明（必须先读）

**没有模型能精准稳定预测比分**。足球存在大量不可量化变量（红牌、意外伤病、战术临场调整、默契球、心态波动），模型只能算出「概率分布」，仅作参考。

- 国内网络购彩属于违法行为；本技能仅用于赛事数据分析与观赛娱乐
- 体育博彩长期从数学期望上必然亏损，**不要用模型做投注决策**
- 所有输出必须是概率分布（如 1-1 22%），**不允许输出"确定比分"**

---

## 核心结论（诚实边界，必须遵守）

1. 模型输出 = 概率分布，不是预测值
2. 短期准确率极低：单场、小联赛误差极大；模型只在大样本长期统计下体现概率优势
3. 强随机性（红牌/误判/乌龙/临场变阵）与人为因素（默契球、资金流向）无法量化
4. 回测必须如实记录真实命中率（比分精确命中 / 胜平负 / 大小球），不伪造达标数字
5. 任何算法变更必须先记入 `CHANGELOG.md` 再实施（含前后指标对比与恢复方法）

## 一、数据维度（建模数据源）

### 量化数据（模型处理）
| 类别 | 字段 |
|------|------|
| 攻防数据 | 近5/10场进球、失球、场均进/失球、主场/客场场均攻防 |
| 对战往绩 | 近3次交手比分、进球效率、主客场交手差异 |
| 联赛强度 | 联赛场均进球、联赛防守平均水平（英超/中超/荷甲差异极大） |
| 排名战意 | 积分榜位置、保级/争冠/欧战战意权重、杯赛赛程密集度 |
| 球员 | 主力射手进球效率、核心中场出勤、后防伤病、门将扑救均值、停赛名单 |
| 环境 | 主客场胜率、天气（暴雨/高温）、草皮、赛程间隔天数、身价差距、历史盘口 |

### 定性数据（人工加权修正，不直接进模型）
临场战术调整、更衣室状态、新闻流言、教练风格博弈。

### 数据时效
只取**近 2 个完整赛季 + 近期 10 场**，久远赛季参考价值极低。

## 二、算法类型（从简单到高阶）

### 1. 泊松分布（基础、首选）
核心逻辑：球队单场进球数近似泊松分布，先算两队「预期进球 λ」，再组合出各比分概率。

```
主队预期进球 λ1 = 联赛场均进球 × 主队进攻强度 × 客队防守系数
客队预期进球 λ2 = 联赛场均进球 × 客队进攻强度 × 主队防守系数

进攻强度 = 球队场均进球 / 联赛场均进球
防守系数 = 球队场均失球 / 联赛场均失球

P(主队进 k 球) = λ1^k × e^(-λ1) / k!
P(比分 a:b) = P(主队 a 球) × P(客队 b 球)
```

遍历 0..8 球组合，输出各比分概率并排序。

### 2. 负二项回归（优化版泊松）
解决进球数据"方差 > 均值"的离散问题，比普通泊松更贴合足球数据。实现需 `statsmodels` 或手写 MLE，**默认泊松可用时优先泊松，数据量大时升级负二项**。

### 3. 机器学习（可选进阶）
- **XGBoost / LightGBM / 随机森林**：把比分/胜平负当分类标签，学习攻防、体能、主客场特征关联，输出各比分概率
- **LSTM**：处理球队状态时序，适合长周期赛事
- **ML 教训（本仓库已验证）**：独立随机+小样本下 ML 学到的是噪声；足球 ML 必须用 ≥2 赛季大样本 + 严格时间切分，且结果以留出集验证为准

### 4. 混合加权模型（实战推荐）
```
最终概率 = 泊松概率 × 战意权重 × 伤病权重 × 主客场修正
```
人工叠加修正纯数学模型的偏差；权重调整必须记 CHANGELOG。

## 三、实操步骤（Python 流程）

### 步骤 0：Git 同步拉取（开始前）
```bash
cd <项目根目录> && git pull origin main --rebase 2>/dev/null || echo "pull skipped"
```
远端正式写操作走 GitHub MCP 或本地 git push（代理已通）；本地 commit 作备份。

### 步骤 1：数据采集
- 数据源：football-data.org（免费 API key）、雷速/飞哥 API、手动 CSV 导入
- 字段：`match_id, league, season, round, date, home, away, home_goals, away_goals, home_xg, away_xg, weather, home_rank, away_rank`
- 首次初始化：导入近 2 赛季 + 近 10 场数据到 `data/matches.csv`（或 MySQL，需配置）

### 步骤 2：数据清洗（最重要）
1. 剔除无效场次：赛季中途换帅首场、球队大规模换血、青年队替补场次
2. 归一化：身价/体能/排名不同量级标准化
3. 缺失值：伤病空缺、延期比赛直接删除样本（不填充臆测值）

### 步骤 3：数据集划分
- 训练 70% / 验证 20% / 测试 10%
- **严格时间切分**：按时间顺序切，不允许随机打乱（防未来数据泄漏）
- 留出段只做一次最终验证，不参与调参

### 步骤 4：模型训练与调参
1. 泊松模型算基础 λ
2. 可选 XGBoost 学习特征权重（如"主力门将伤缺"→ 拉高对手 λ）
3. 调参：避免过拟合冷门大比分历史（可截断 8+ 球概率）

### 步骤 5：输出（概率分布，不是确定比分）
```
## 曼城 vs 阿森纳 预测
推荐比分（最多2个）: 1-1 22% | 2-1 18%
胜平负: 主胜 45% 平 27% 客胜 28%
大小球(2.5): 大 52% 小 48%
总进球: 0球 15% | 1球 28% | 2球 27% | 3球 17% ...
半全场(9选1): 胜胜 30% | 平胜 20% | 平平 17% | 平负 12% ...
```
同时输出模型依据（λ1/λ2、权重修正项、爆冷风险评级）。

**输出契约（必须遵守）**：
- 每场推荐比分 **最多 2 个**（`top_n=2`，完整比分矩阵保留用于计算）
- 每场必须包含：胜平负 `result_prob`、大球概率 `over25`、总进球分布 `goals_dist`、爆冷风险 `upset_risk`
- 每场必须输出半全场：9 档分布 `half_full` + 前三推荐 `half_full_top`
- 比分展示同时保留 `top_scores`（数学概率最高，审计用）与 `recommended_scores`（模态+总进球≥3候选，去重）；`high_goal_score_candidates` 只是场景候选，不代表其概率高于模态比分

### 步骤 6：赛后迭代
每场赛果录入数据集，定期重训更新攻防系数；复盘记录写入 `data/predictions.json` 与 CHANGELOG。

## 四、模型无法解决的缺陷（必须如实告知）

1. 红牌/点球误判/乌龙/临场战术大变/心态——无法录入
2. 低级别联赛默契球、操控赛果——历史规律直接失效
3. 盘口热度、资金流向改变比赛走势——不在球队数据范畴
4. 单场误差极大；顶级联赛相对规律更强，小众联赛基本无参考性

### 完整预测流程（每期执行）

1. 赛程页取可投注赛事 → 对阵详情页取 H2H/近况/伤停 → zgzcw 取赔率
2. `full_predict(odds, weights, top_n=2)`：市场赔率反推 λ → 三层加权（H2H/近况/伤停调 home/away/draw 乘数）→ 输出推荐比分（≤2 个）/胜平负/大小球/总进球 8 档/半全场 9 档；需要按历史画像修正时改用 `anomaly_predict(odds, tier, bias)`（市场λ→Dixon-Coles→联赛比分偏置表→修正后胜平负/比分/半全场，输出 `anomaly_adjusted` 层）
3. 历史增强：有可核验近期5场与H2H时，使用 `history_enhanced` 层——近期主客攻防60% + 市场λ40%，H2H只作弱校正（方向≤8%、总进球≤15%）；联赛总进球均值先除以2再作为单队基准。无可核验历史时历史权重降为0并写明数据缺口，不用赔率伪装成历史分析。
4. 历史异常画像：`anomaly_analysis(history)` 跑相关联赛历史（德甲/德乙 2025-26 已落盘），对照爆冷/大比分/卖分/控分四类统计指纹，单场异常按旗标提示，写入 `recent_upset_check`
5. 赛后按 胜平负/比分精确/总进球 三指标复盘（半全场命中率待积累样本后单列）

### 半全场（HT/FT）预测（2026-08-19 新增）

- **原理**：把全场进球拆成两段独立增量泊松——上半场 λ₁' = λ×45%，下半场 λ₂' = λ×55%；先枚举半场比分（h1,a1）与下半场比分（h2,a2），全场比分=(h1+h2, a1+a2)，映射为 9 类：`胜胜/胜平/胜负/平胜/平平/平负/负胜/负平/负负`（半场结果 + 全场结果）
- **输出字段**：`half_full`（9 类概率，归一化到 1）、`half_full_top`（Top3 推荐，`algorithms.half_full_distribution / top_half_full`）
- **参数口径**：半全场从该场**最终 λ** 重算（integrated_v2 → integrated → 市场反推），与对外胜平负同源；未叠加 Dixon-Coles 低分修正与平局区人工权重的版本，其平局边际与主胜平负可能差 ≤3 个百分点（如实注明）；`anomaly_adjusted` 层通过「修正后胜平负反推有效λ」生成半全场，全场平局边际与胜平负一致（±2pp 校验通过）
- **玩法说明**：竞彩半全场是 9 选 1，单类概率普遍 10-35%，无长期稳定优势；命中率声明需积累实盘复盘样本后才可给出

### 爆冷/卖分风险（实证结论，2026-08-18）

- 低级别联赛爆冷率 2.3 倍于顶级（德乙 14% vs 德甲 6%，排名差≥10）
- **卖分高风险画像**：低级别 + 赛季末段（最后5轮）+ 强弱悬殊 → 爆冷率 25%
- 平局是大热爆冷的主要形式（被逼平率 17-21%）→ 加权时平局区适当上调
- 诚实边界：风险画像 ≠ 操控证据；杯赛淘汰赛战意更真实；单场异常无法定性

### 历史异常分析（爆冷/大比分/卖分/控分画像，2026-08-19 新增）

**入口**：`algorithms.anomaly_analysis(matches, league_name, tier, league_avg)` → 报告落盘 `data/anomaly_reports.json`；数据由 `python fetch_history.py` 拉取（openligadb，含半场比分与最终排名）。

四类画像与规则（全部为**统计指纹**，见下方诚实边界）：

1. **爆冷**：大热=最终排名差≥6（`upset_stats`）。按赛季时段拆解大热输球率/被逼平率。
2. **大比分**：常见比分与总进球的实际频率 vs 独立泊松期望（两队均按 λ=联赛均分/2），ratio>1.2 视为该比分系统性偏多；另统计 6+ 球大比分场次率。
3. **卖分**：末5轮 + 排名差≥10 + 大热不胜（`sell_fingerprints`）；赛季末中游对中游（无欲无求）低进球率 vs 联赛基线。
4. **控分**：队伍级窄分差（0-0/1-0/0-1/1-1）率显著高于联赛基线；"持1-0到终场"次数聚类；同轮≥2 个大热被逼平的关联信号。

**2025-26 实证基线（本次分析产出，供后续对照）**：

| 指标 | 德甲（顶级） | 德乙（低级别） |
|---|---|---|
| 大热(差≥6)输球率 | 10.9% | 20.5% |
| 末5轮大热输球率 | 14.3% | **33.3%** |
| 大热被逼平率 | 19.9% | 24.4% |
| 6+球大比分率 | 10.8% | 7.2% |
| 比分偏多信号 | 3:1 (ratio 1.53) | 2:1 (1.36)、1:0 (1.25) |
| 末5轮悬殊场大热不胜 | 3 场（拜仁3:3海登海姆等） | 4 场（汉诺威3:3等） |
| 控分指纹队伍 | 门兴 窄分差41.2% | 沙尔克 窄分差44.1%、持1-0到终场5次 |

**诚实边界（必须遵守）**：
- 以上全部为统计指纹，**不构成任何"操控/卖分证据"**；单场异常（如拜仁 3:3）无法定性，可能有真实原因（轮换、伤停、无欲无求）
- 赛季末样本量小（末5轮悬殊场每联赛 21-24 场），置信区间宽
- 引用到单场预测时，只作风险提示（"该队有控分指纹"），不得写成"这场被操纵"
- 杯赛淘汰赛战意真实，卖分画像主要适用于联赛末段常规赛

**应用到预测（2026-08-19 实战）**：`build_score_bias(历史)` 生成联赛比分偏置表（经验收缩 k=8，向 1.0 收缩再截断 0.5-2.0，避免小样本噪声过度扭曲），`anomaly_predict(odds, tier, bias)` 按层级套用：顶级层用德甲偏置（4:0/3:1/3:3 偏多），低级别层用德乙偏置（2:1/1:0/3:3 偏多）。已对周三001-008 输出 `anomaly_adjusted` 层。偏置表存 `data/bias_profiles.json`。
